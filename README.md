An entry for the [make.fun](https://make.fun) competition
[Deadpan Forecasts for Cities That Do Not Exist](https://make.fun/bounty/u-coral-ibis-18-deadpan-forecasts-for-cities-that-do-151d4d8c):
a program that writes one absurd yet believable deadpan weather line for an
invented city to `/output/entry.txt`.

## Run

```sh
node main.ts
```

It writes the forecast to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
